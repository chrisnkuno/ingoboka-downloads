# Ingoboka for Windows

[Download Ingoboka 0.1.1 for Windows](https://github.com/chrisnkuno/ingoboka-downloads/releases/download/v0.1.1/Ingoboka-Setup-0.1.1.exe)

Open the downloaded file and follow the installer. Ingoboka works without internet and keeps records on this computer. The app has a Kinyarwanda, French, and English help guide.

**Windows security notice:** This 0.1.1 installer is unsigned. Windows may show **Windows protected your PC** or block the installer. A new signed download can still show a SmartScreen warning until it builds reputation. Do not disable Windows Security to install Ingoboka. For an installation without that download warning, wait for a Microsoft Store release.

After the first meeting, open **File → Open backups folder** and copy the newest backup to a USB drive or another trusted device. Records do not sync between devices.

This repository contains installer downloads only. The source code and the group's example workbooks are not published here.
