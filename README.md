# Ingoboka

**Recommended for Windows:** [Open Ingoboka in your browser](https://ingoboka.vercel.app). Open it once while connected to the internet and wait for **Ready to use without internet**. In Microsoft Edge or Chrome, use **Install app** from the browser menu to give it a desktop or Start-menu icon. It then opens and works offline.

Records stay in that browser profile on your computer. Use the same browser and address each time. After every meeting, click **Download backup** and copy the JSON file to a USB drive or another trusted device. Clearing site data or changing computers requires restoring that backup.

## Older Windows installer

[Download Ingoboka 0.1.1 for Windows](https://github.com/chrisnkuno/ingoboka-downloads/releases/download/v0.1.1/Ingoboka-Setup-0.1.1.exe)

The older installer also works offline, but its 0.1.1 release is unsigned and may be blocked by Windows. The web app above avoids downloading a Windows executable. Both versions include the Kinyarwanda, French, and English help guide.

**Windows security notice:** This 0.1.1 installer is unsigned. Windows may show **Windows protected your PC** or block the installer. A new signed download can still show a SmartScreen warning until it builds reputation. Do not disable Windows Security to install Ingoboka. For an installation without that download warning, wait for a Microsoft Store release.

After the first meeting, open **File → Open backups folder** and copy the newest backup to a USB drive or another trusted device. Records do not sync between devices.

This repository contains installer downloads only. The source code and the group's example workbooks are not published here.
